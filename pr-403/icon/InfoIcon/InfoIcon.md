# InfoIcon

- Kind: constant
- Import: `import { InfoIcon } from "shelving/icon/InfoIcon";`

Icon for `status="info"` (the default) in `<Icon>`.
- Default is the Heroicons `InformationCircleIcon`.
- Swap it for your own icon with a `paths` entry for `shelving/icon/InfoIcon` in your `tsconfig.json`. See `README.md` in this folder.
