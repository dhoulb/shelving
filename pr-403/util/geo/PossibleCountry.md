# PossibleCountry

- Kind: type
- Import: `import { PossibleCountry } from "shelving/util/geo";`

A value that can possibly be resolved to a `Country` — either a country code or the literal `"detect"`.

## Signatures

```ts
Country | "detect"
```

## Types

- [Country](Country.md): Two-letter ISO 3166-1 alpha-2 country code string (a key of COUNTRIES).
