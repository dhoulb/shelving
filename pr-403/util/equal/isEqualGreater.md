# isEqualGreater()

- Kind: function
- Import: `import { isEqualGreater } from "shelving/util/equal";`

Is unknown value `left` greater than or equal to `right` (using `compareAscending()`)?

## Signatures

```ts
isEqualGreater(left: unknown, right: unknown): void
```

## Parameters

| Param | Type | Description |
| --- | --- | --- |
| `left` | `unknown` | The value to compare. |
| `right` | `unknown` | The value to compare against. |

## Returns

| Type | Description |
| --- | --- |
| `unknown` | `true` if `left` sorts after or equal to `right`. |
