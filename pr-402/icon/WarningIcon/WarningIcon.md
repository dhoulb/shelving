# WarningIcon

- Kind: constant
- Import: `import { WarningIcon } from "shelving/icon/WarningIcon";`

Icon for `status="warning"` and `status="danger"` in `<Icon>`.
- Default is the Heroicons `ExclamationTriangleIcon`.
- Swap it for your own icon with a `paths` entry for `shelving/icon/WarningIcon` in your `tsconfig.json`. See `README.md` in this folder.
