# IndentVariants

- Kind: interface
- Import: `import { IndentVariants } from "shelving/ui";`

Variant props for the inline-padding ("indent", left + right) of a component, e.g. `indent="normal"`.

## Signatures

```ts
{
	indent?: IndentVariant | undefined;
}
```

## Properties

| Property | Type | Description |
| --- | --- | --- |
| `indent` | `IndentVariant \| undefined` | Inline-padding (left + right) of the element, keeping its content off the edges. Optional. |
