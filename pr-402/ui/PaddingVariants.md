# PaddingVariants

- Kind: interface
- Import: `import { PaddingVariants } from "shelving/ui";`

Variant props for the block-padding (top + bottom) of a component, e.g. `padding="large"`.

## Signatures

```ts
{
	padding?: SpaceValue | undefined;
}
```

## Properties

| Property | Type | Description |
| --- | --- | --- |
| `padding` | `SpaceValue \| undefined` | Block-padding (top + bottom) of the element. Optional. |
