# GridVariants

- Kind: interface
- Import: `import { GridVariants } from "shelving/ui";`
- Extends: `GapVariants`

Variant props for grid layout, e.g. `columns={3} gap="normal"`.

## Signatures

```ts
{
	columns?: ColumnsVariant | undefined;
}
```

## Properties

| Property | Type | Description |
| --- | --- | --- |
| `columns` | `ColumnsVariant \| undefined` | Number of equal-width columns. Defaults to `2`. |
