# RemoveIcon

- Kind: constant
- Import: `import { RemoveIcon } from "shelving/icon/RemoveIcon";`

Icon to remove an item, e.g. the remove buttons on `<ArrayInput>`, `<DictionaryInput>` and `<ImageInput>`. The pair of `AddIcon`.
- Default is the Heroicons `XMarkIcon`, the same as `CloseIcon`.
- Swap it for your own icon with a `paths` entry for `shelving/icon/RemoveIcon` in your `tsconfig.json`. See `README.md` in this folder.
