# DocumentationFrameProps

- Kind: interface
- Import: `import { DocumentationFrameProps } from "shelving/ui";`
- Extends: `PlaygroundCode`

Props for `<DocumentationFrame>` — the code and CSS to run, plus a title for the frame.

## Signatures

```ts
{
	title?: string | undefined;
}
```

## Properties

| Property | Type | Description |
| --- | --- | --- |
| `title` | `string \| undefined` | Accessible title of the frame. Defaults to `"Preview"`. |
