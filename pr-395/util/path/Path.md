# Path

- Kind: type
- Import: `import { Path } from "shelving/util/path";`

Either an absolute or relative path.

## Signatures

```ts
AbsolutePath | RelativePath
```

## Types

- [AbsolutePath](AbsolutePath.md): Absolute path string starting with a / slash.
- [RelativePath](RelativePath.md): Relative path string that is . dot, or starts with ./ dot slash.
