# CloseIcon

- Kind: constant
- Import: `import { CloseIcon } from "shelving/icon/CloseIcon";`

Icon to close something, e.g. the close button on `<Dialog>` and `<SidebarLayout>`.
- Default is the Heroicons `XMarkIcon`.
- Swap it for your own icon with a `paths` entry for `shelving/icon/CloseIcon` in your `tsconfig.json`. See `README.md` in this folder.
