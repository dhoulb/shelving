# LeftIcon

- Kind: constant
- Import: `import { LeftIcon } from "shelving/icon/LeftIcon";`

Chevron that points left.
- Default is the Heroicons `ChevronLeftIcon`.
- Swap it for your own icon with a `paths` entry for `shelving/icon/LeftIcon` in your `tsconfig.json`. See `README.md` in this folder.
