# DownIcon

- Kind: constant
- Import: `import { DownIcon } from "shelving/icon/DownIcon";`

Chevron that points down.
- Default is the Heroicons `ChevronDownIcon`.
- Swap it for your own icon with a `paths` entry for `shelving/icon/DownIcon` in your `tsconfig.json`. See `README.md` in this folder.
