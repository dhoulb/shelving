# Endpoints

- Kind: type
- Import: `import { Endpoints } from "shelving/api";`

An immutable list of endpoints.

## Signatures

```ts
ImmutableArray<AnyEndpoint>
```

## Types

- [ImmutableArray](../util/array/ImmutableArray.md): Immutable array: an array that cannot be changed.
- [AnyEndpoint](AnyEndpoint.md): An Endpoint with any payload and result type, for use where the specific types don't matter.
