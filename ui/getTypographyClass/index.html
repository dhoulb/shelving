    getTypographyClass()function

    getTypographyClass({ tint, weight, font, case: caseValue, size, leading, ...props }: TypographyVariants): string
    ParamType
    propsTypographyVariants
    Typographic variant props — colour, font-family, weight, case, size, line height, tint, alignment, wrap, balance, and truncate, applied via getTypographyClass() required
        .sizeSizeVariant
    Font size of the element.
        .leadingLeadingVariant
    Line height of the element. Text inside inherits it, unless it sets its own font size.
        .tintTintVariant
    Set CSS text color: to one of the shades of the current tint ladder.
        .fontFontVariant
    Font family of the element.
        .caseCaseVariant
    Text case of the element.
        .weightWeightVariant
    Font weight of the element.
        .leftboolean
    Align text to the start of the line (LTR: left).
        .centerboolean
    Centre text horizontally.
        .rightboolean
    Align text to the end of the line (LTR: right).
        .wrapboolean
    Enable wrapping.
        .nowrapboolean
    Disable wrapping.
        .balanceboolean
    Balance the length of the lines, so the last line is not much shorter than the others.
        .truncateboolean
    Cut overflowing text to one line with an ellipsis (on a block or a flex item).
    Return
    string
    The combined typography class string (empty when no variants apply).

    Get the typography class for a component from its typographic variant props.

    Maps the colour, size, line height, weight, font, case, tint, alignment, wrap, balance, and truncate variant props to their CSS classes — the color variant is composed in via getColorClass().

    The typography variant props set an element's text styling from a single helper — <Heading font="title" size="large">, <Paragraph weight="strong" center>, <Small case="upper">. They're overrides for one-off changes; for an app-wide change, retune the variables below in a theme file.

    getTypographyClass({ color, size, leading, weight, font, case, tint, left, center, right, wrap, nowrap, balance, truncate }) maps each prop to a class (e.g. size="large" → size-large, leading="tight" → leading-tight, font="title" → font-title, weight="strong" → weight-strong, case="upper" → case-upper), and combines them with text alignment, tint colour, wrapping, and truncation. TypographyVariants extends ColorVariants, so it also accepts color and composes getColorClass() internally — anything that opts into typography gets the color variant for free and no longer needs to extend ColorVariants or call getColorClass() separately. (getColorClass() stays exported for the rare element that wants colour without typography, such as <Icon>.) It also supersedes the former getFontClass(), getSizeClass(), and getWeightClass() helpers, which were merged into this module.

    The balance flag sets text-wrap: balance, so the lines of a short block (a heading or a one-sentence paragraph) are about the same length: <Paragraph balance>.

    The truncate flag cuts overflowing text to one line and ends it with an ellipsis. It works on a block element or a flex item, not on inline text. When the text is inside a wrapper that is a flex item, give that wrapper grow (see getWidthClass()), so it can shrink below the width of the text.

    The semantic faces, weights, sizes, and cases are aliases of the base values, so a theme usually only needs to move the small set of base variables.

    Theme variables

    The following :root variables are defined by this module and can be overridden in a theme file to adjust default styling across the whole app.

    --font-bodyvar(--font-sans)Body baseline.
    --font-labelvar(--font-sans)Labels.

    --size-1x … --size-10xcalc(var(--size-normal) * n)Direct multiples of normal size.

    Line height

    VariableDefaultUsed for
    --leading-autoround(clamp(1.05em, calc(1em + 0.5rem), 1.5em), 1px)Default: about 1.5 for small text, less for big text.
    --leading-singleround(1em, 1px)One line, no gap. For icons and one-line labels.
    --leading-tightround(1.25em, 1px)Small text in a close group, such as a title and a short description in a tile.
    --leading-normalround(1.5em, 1px)A fixed 1.5 at every size.
    --leading-looseround(1.75em, 1px)Long body copy.

    Each value is rounded to a whole pixel, so stacked rows do not move by a pixel when the browser rounds them.

    How line height reaches an element:

    • The body uses --leading-auto. A block that sets its own font size (<Heading>, <Label>, <Button>, …) has a hook, for example --heading-leading, that defaults to --leading-auto.
    • Inline elements (<Strong>, <Span>, <Small>, …) set no line height. They inherit it.
    • The size prop sets --leading-auto too. A line height in em inherits as a fixed pixel value, so text with a new size needs a new line height.
    • The leading prop sets the line height of that element only, and wins over size and over component hooks: <Column size="small" leading="tight">. Text inside inherits it, unless it sets its own size.
    • To change the default for the whole app, override --leading-auto at :root.

    Case

    VariableDefaultUsed for
    --case-titlenonetext-transform for titles and headings.
    --case-bodynonetext-transform for body text and the body baseline.
    --case-labeluppercasetext-transform for labels and tags.
    --case-codenonetext-transform for code and preformatted text.
