    Blockquotecomponent

    Blockquote({ children, className, ...props }: BlockquoteProps): ReactElement
    ParamType
    propsBlockquoteProps
    Props for Blockquote — colour, space, and typography variants plus optional children. required
    Return
    ReactElement

    Quoted block of text — rendered as <blockquote>.

    A block of quoted text. Renders a <blockquote> with a line on its left edge.

    Things to know:

    • Put block content inside it, such as <Paragraph>. It trims the outer margins of its first and last children, so its padding is not doubled. Set trim={false} to keep them.
    • It is display: flow-root, so the margins of its children stay inside it.
    • The line is painted from the tint ladder. Set color= on it (or an ancestor) to recolour the line.
    • Inside <Prose> a raw <blockquote> gets the same styles, so Markdown quotes match.
    • Composes the standard block variants: color, space, padding, indent, width, plus typography.

    Styling

    Override these hooks at :root. The tint hook (--blockquote-border) is declared again in every tint scope, so override it at :root, .tint.

    VariableStylesDefault
    --blockquote-borderColour of the left linevar(--tint-90)
    --blockquote-strokeWidth of the left line (one length)var(--stroke-normal) (1px)
    --blockquote-spaceOuter block margin (top and bottom)var(--space-paragraph) (16px)
    --blockquote-paddingInner top and bottom padding (one length)var(--space-small) (12px)
    --blockquote-indentInner left padding (one length)var(--space-normal) (16px)
    --blockquote-colorText colourinherit
    --blockquote-fontFont familyinherit
    --blockquote-weightFont weightvar(--weight-normal) (400)
    --blockquote-sizeFont sizeinherit
    --blockquote-leadingLine heightinherit
    --blockquote-alignText alignmentleft

    Global tokens it reads: --tint-90, --stroke-normal, --space-paragraph, --space-small, --space-normal, --weight-normal.
