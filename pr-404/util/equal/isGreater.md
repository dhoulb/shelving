# isGreater()

- Kind: function
- Import: `import { isGreater } from "shelving/util/equal";`

Is unknown value `left` greater than `right` (using `compareAscending()`)?

## Signatures

```ts
isGreater(left: unknown, right: unknown): void
```

## Parameters

| Param | Type | Description |
| --- | --- | --- |
| `left` | `unknown` | The value to compare. |
| `right` | `unknown` | The value to compare against. |

## Returns

| Type | Description |
| --- | --- |
| `unknown` | `true` if `left` sorts after `right`. |
