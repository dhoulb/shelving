# ExpandIcon

- Kind: constant
- Import: `import { ExpandIcon } from "shelving/icon/ExpandIcon";`

Icon to expand, e.g. to enter fullscreen, used in `<FullscreenButton>`.
- Default is the Heroicons `ArrowsPointingOutIcon`.
- Swap it for your own icon with a `paths` entry for `shelving/icon/ExpandIcon` in your `tsconfig.json`. See `README.md` in this folder.
