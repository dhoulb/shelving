# DurationVariants

- Kind: interface
- Import: `import { DurationVariants } from "shelving/ui";`

Variant props for the transition duration of an element, e.g. `duration="fast"`.

## Signatures

```ts
{
	duration?: DurationValue | undefined;
}
```

## Properties

| Property | Type | Description |
| --- | --- | --- |
| `duration` | `DurationValue \| undefined` | Transition duration of the element. Optional. |
