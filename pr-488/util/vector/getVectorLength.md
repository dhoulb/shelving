# getVectorLength()

- Kind: function
- Import: `import { getVectorLength } from "shelving/util/vector";`

Get the length (magnitude) of a vector.

## Signatures

```ts
getVectorLength(vector: VectorArray): number
```

## Parameters

| Param | Type | Description |
| --- | --- | --- |
| `vector` | `VectorArray` | The vector to measure. |

## Returns

| Type | Description |
| --- | --- |
| `number` | The square root of the sum of the squares of its numbers. |
