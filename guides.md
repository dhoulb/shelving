# Guides

Guides that explain how to use Shelving in a real project, and how to write code in the Shelving style.


## Pages

- [Building with Shelving](guides/building-with-shelving.md): A guide to structuring a full-stack TypeScript project on Shelving. It describes a proven layout for a project with a React frontend, a Bun HTTP API, and a shared contract package between them — where Shelving provides the schema system, endpoint contracts, request handling, data providers, and UI component library.
- [Code styleguide](guides/styleguide.md): The canonical code style for the shelving codebase and for any project built in its style. AGENTS.md signposts this file — read it fully before writing any code. Rules are stated as requirements — deviate only with a stated reason.
