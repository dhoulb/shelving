    Preformattedcomponent

    Preformatted({ children, className, ...variants }: PreformattedProps): ReactElement
    ParamType
    variantsPreformattedProps
    Props for Preformatted — space, colour, typography, width, and padding variants plus a wrap toggle. required
        .wrapboolean
    Enable line wrapping (default is nowrap).
    Return
    ReactElement

    Preformatted block of text — rendered as <pre>.

    • Lines are not wrapped by default — overflowing content scrolls horizontally within the block.
    • Pass wrap to wrap long lines instead; newlines and indentation are preserved either way.

    A block of preformatted text, such as code or terminal output. Renders a <pre> in a box with a monospace font.

    Things to know:

    • Newlines, spaces and tabs show as written. Tabs are two spaces wide.
    • Long lines do not wrap. The block scrolls left and right. Set wrap to wrap long lines.
    • The block is always full width.
    • The box is painted from the tint ladder. Set color= on it, or color= or status= on an ancestor such as a <Card>, to recolour it.
    • Inside <Prose> a raw <pre> gets the same styles, so Markdown code blocks match.
    • For a short piece of code inside a sentence, use <Code>.

    Styling

    Override these hooks at :root. The tint hooks (--preformatted-border, --preformatted-background, --preformatted-color) are declared again in every tint scope, so override them at :root, .tint.

    VariableStylesDefault
    --preformatted-backgroundBackgroundvar(--tint-90)
    --preformatted-colorText colourvar(--tint-00)
    --preformatted-borderBorder colour (width is --preformatted-stroke)var(--tint-80)
    --preformatted-strokeBorder width (one length)var(--stroke-normal) (1px)
    --preformatted-radiusCorner radiusvar(--radius-normal) (16px)
    --preformatted-spaceOuter block margin (top and bottom)var(--space-paragraph) (16px)
    --preformatted-paddingInner top and bottom padding (one length)var(--space-normal) (16px)
    --preformatted-indentInner left and right padding (one length)var(--space-normal) (16px)
    --preformatted-shadowDrop shadownone
    --preformatted-transitionTransitionall var(--duration-fast) (150ms)
    --preformatted-focus-borderFocus outline colour (width is --stroke-focus)var(--color-focus)
    --preformatted-fontFont familyvar(--font-code) (monospace)
    --preformatted-weightFont weightvar(--weight-code) (500)
    --preformatted-sizeFont sizevar(--size-normal) (16px)
    --preformatted-leadingLine heightvar(--leading-auto)

    Global tokens it reads: the tint ladder --tint-00 / --tint-80 / --tint-90, plus --stroke-normal, --stroke-focus, --radius-normal, --space-paragraph, --space-normal, --duration-fast, --color-focus, --font-code, --weight-code, --size-normal, --leading-auto.
