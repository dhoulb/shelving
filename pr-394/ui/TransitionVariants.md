# TransitionVariants

- Kind: interface
- Import: `import { TransitionVariants } from "shelving/ui";`

Variant props shared by every transition component.

## Signatures

```ts
{
	overlay?: boolean | undefined;
}
```

## Properties

| Property | Type | Description |
| --- | --- | --- |
| `overlay` | `boolean \| undefined` | Render this transition above other transitions (z-index: 100 on the group). Optional. |
