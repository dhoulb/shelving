# PossibleMetaAssets

- Kind: type
- Import: `import { PossibleMetaAssets } from "shelving/ui";`

Set of input linked assets in `(href)[]` format, before hrefs are resolved.

## Signatures

```ts
ImmutableArray<Nullish<PossibleLink>>
```

## Types

- [ImmutableArray](../util/array/ImmutableArray.md): Immutable array: an array that cannot be changed.
- [Nullish](../util/null/Nullish.md): Nullish is the value or null or undefined.
- [PossibleLink](../util/link/PossibleLink.md): Anything that can be turned into an <a href>.
