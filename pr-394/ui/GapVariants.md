# GapVariants

- Kind: interface
- Import: `import { GapVariants } from "shelving/ui";`

Variant props for the gap between a component's children, e.g. `gap="large"`.

## Signatures

```ts
{
	gap?: SpaceValue | undefined;
}
```

## Properties

| Property | Type | Description |
| --- | --- | --- |
| `gap` | `SpaceValue \| undefined` | Gap between child elements. Optional. |
