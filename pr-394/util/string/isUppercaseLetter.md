# isUppercaseLetter()

- Kind: function
- Import: `import { isUppercaseLetter } from "shelving/util/string";`

Is the first character of a string an uppercase letter?

## Signatures

```ts
isUppercaseLetter(str: string): boolean
```

## Parameters

| Param | Type | Description |
| --- | --- | --- |
| `str` | `string` | The string whose first character is tested. |

## Returns

| Type | Description |
| --- | --- |
| `boolean` | `true` if the first character of `str` is an uppercase A–Z letter, otherwise `false`. |
