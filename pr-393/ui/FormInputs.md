# FormInputs

- Kind: component
- Import: `import { FormInputs } from "shelving/ui";`

Show a `SchemaInput` for every property in the current form's schema.

## Signatures

```ts
FormInputs(): ReactElement
```

## Returns

| Type | Description |
| --- | --- |
| `ReactElement` | A fragment of `FormInput` elements, one per schema property. |

## Examples

```ts
<FormInputs />
```
