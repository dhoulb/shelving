# StrokeVariants

- Kind: interface
- Import: `import { StrokeVariants } from "shelving/ui";`

Variant props for the border thickness of a component, e.g. `stroke="thick"`.

## Signatures

```ts
{
	stroke?: StrokeVariant | undefined;
}
```

## Properties

| Property | Type | Description |
| --- | --- | --- |
| `stroke` | `StrokeVariant \| undefined` | Border thickness of the component. Optional. |
