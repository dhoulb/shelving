# GridProps

- Kind: interface
- Import: `import { GridProps } from "shelving/ui";`
- Extends: `BlockVariants`

Props for the `<Grid>` component.

## Signatures

```ts
{
	as?: BlockElement | "ul" | "ol" | undefined;
}
```

## Properties

| Property | Type | Description |
| --- | --- | --- |
| `as` | `BlockElement \| "ul" \| "ol" \| undefined` | Element this `<Grid>` renders as, e.g. "ul" to output a "<ul>" Defaults to `"div"`. |
