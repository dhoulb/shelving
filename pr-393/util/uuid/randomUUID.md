# randomUUID()

- Kind: function
- Import: `import { randomUUID } from "shelving/util/uuid";`

Return a random UUID (v4) as a 32-character lowercase hex string with dashes stripped.

## Signatures

```ts
randomUUID(): string
```

## Returns

| Type | Description |
| --- | --- |
| `string` | A random 32-character lowercase hex UUID string. |
