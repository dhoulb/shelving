# sumNumbers()

- Kind: function
- Import: `import { sumNumbers } from "shelving/util/number";`

Sum an iterable set of numbers and return the total.

## Signatures

```ts
sumNumbers(nums: Iterable<number>): number
```

## Parameters

| Param | Type | Description |
| --- | --- | --- |
| `nums` | `Iterable<number>` | The iterable of numbers to sum. |

## Returns

| Type | Description |
| --- | --- |
| `number` | The total of all the numbers (`0` if `nums` is empty). |
