# formatBoolean()

- Kind: function
- Import: `import { formatBoolean } from "shelving/util/format";`

Format a boolean as `"Yes"` or `"No"`.

## Signatures

```ts
formatBoolean(value: boolean): string
```

## Parameters

| Param | Type | Description |
| --- | --- | --- |
| `value` | `boolean` | Boolean value to format. |

## Returns

| Type | Description |
| --- | --- |
| `string` | `"Yes"` if `value` is `true`, otherwise `"No"`. |
