# shuffleArray()

- Kind: function
- Import: `import { shuffleArray } from "shelving/util/array";`

Return a shuffled version of an array or iterable.

## Signatures

```ts
shuffleArray(items: PossibleArray<T>): ImmutableArray<T>
```

## Parameters

| Param | Type | Description |
| --- | --- | --- |
| `items` | `PossibleArray<T>` | The array or iterable to shuffle. |

## Returns

| Type | Description |
| --- | --- |
| `ImmutableArray<T>` | A new array containing the same items in random order. |
