# isLowercaseLetter()

- Kind: function
- Import: `import { isLowercaseLetter } from "shelving/util/string";`

Is the first character of a string a lowercase letter?

## Signatures

```ts
isLowercaseLetter(str: string): boolean
```

## Parameters

| Param | Type | Description |
| --- | --- | --- |
| `str` | `string` | The string whose first character is tested. |

## Returns

| Type | Description |
| --- | --- |
| `boolean` | `true` if the first character of `str` is a lowercase a–z letter, otherwise `false`. |
