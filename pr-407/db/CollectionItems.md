# CollectionItems

- Kind: type
- Import: `import { CollectionItems } from "shelving/db";`

Extract the array of `Item` types from a `Collection` instance.

## Signatures

```ts
Items<CollectionIdentifier<C>, CollectionData<C>>
```

## Types

- [Items](../util/item/Items.md): An array of item objects.
- [CollectionIdentifier](CollectionIdentifier.md): Extract the Identifier type from a Collection instance.
- [CollectionData](CollectionData.md): Extract the Data type from a Collection instance.
