# SuccessIcon

- Kind: constant
- Import: `import { SuccessIcon } from "shelving/icon/SuccessIcon";`

Icon for `status="success"` in `<Icon>`.
- Default is the Heroicons `CheckCircleIcon`.
- Swap it for your own icon with a `paths` entry for `shelving/icon/SuccessIcon` in your `tsconfig.json`. See `README.md` in this folder.
