# shelving/util/debug

- Kind: module
- Import: `import { … } from "shelving/util/debug";`

## Functions

- [debug](debug/debug.md): Convert any unknown value into a readable debug string.
- [debugString](debug/debugString.md): Convert a string into a quoted, escaped debug string.
- [debugHeaders](debug/debugHeaders.md): Convert a set of Headers into a debug string.
- [debugFullRequest](debug/debugFullRequest.md): Debug a full Request as a string including its body.
- [debugFullResponse](debug/debugFullResponse.md): Debug a full Response as a string including its headers and body.
- [debugRequest](debug/debugRequest.md): Convert a Request into a one-line debug string.
- [debugResponse](debug/debugResponse.md): Convert a Response into a one-line debug string.
- [debugArray](debug/debugArray.md): Convert an array into a readable debug string.
- [debugSet](debug/debugSet.md): Convert a Set into a readable debug string.
- [debugMap](debug/debugMap.md): Convert a Map into a readable debug string.
- [debugObject](debug/debugObject.md): Convert an object into a readable debug string.
- [indent](debug/indent.md): Indent a string for nested debug output.
