# RouteComponent

- Kind: type
- Import: `import { RouteComponent } from "shelving/ui";`

React component usable as a route value — a function or class component accepting `RouteProps`.

## Signatures

```ts
FunctionComponent<RouteProps> | ComponentClass<RouteProps>
```

## Types

- `FunctionComponent`
- [RouteProps](RouteProps.md): Props for a component that works as a route in the router.
- `ComponentClass`
