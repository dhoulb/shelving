# FullscreenIcon

- Kind: constant
- Import: `import { FullscreenIcon } from "shelving/icon/FullscreenIcon";`

Icon to enter fullscreen, used in `<FullscreenButton>`.
- Default is the Heroicons `ArrowsPointingOutIcon`.
- Swap it for your own icon with a `paths` entry for `shelving/icon/FullscreenIcon` in your `tsconfig.json`. See `README.md` in this folder.
