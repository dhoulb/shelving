# CloseIcon

- Kind: constant
- Import: `import { CloseIcon } from "shelving/ui";`

Icon to close or remove something, e.g. the close button on `<Dialog>` and the remove buttons on inputs.
- Default is the Heroicons `XMarkIcon`.
- Swap it for your own icon with a `paths` entry for `shelving/ui/icon/CloseIcon` in your `tsconfig.json`. See `README.md` in this folder.
