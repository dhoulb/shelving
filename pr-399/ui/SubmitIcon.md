# SubmitIcon

- Kind: constant
- Import: `import { SubmitIcon } from "shelving/ui";`

Icon for the default `<SubmitButton>`.
- Default is the Heroicons `ArrowRightIcon`.
- Swap it for your own icon with a `paths` entry for `shelving/ui/icon/SubmitIcon` in your `tsconfig.json`. See `README.md` in this folder.
