# ExitFullscreenIcon

- Kind: constant
- Import: `import { ExitFullscreenIcon } from "shelving/ui";`

Icon to exit fullscreen, used in `<FullscreenButton>`.
- Default is the Heroicons `ArrowsPointingInIcon`.
- Swap it for your own icon with a `paths` entry for `shelving/ui/icon/ExitFullscreenIcon` in your `tsconfig.json`. See `README.md` in this folder.
