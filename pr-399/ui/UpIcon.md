# UpIcon

- Kind: constant
- Import: `import { UpIcon } from "shelving/ui";`

Chevron that points up, e.g. the open and close arrow on `<Details>`.
- Default is the Heroicons `ChevronUpIcon`.
- Swap it for your own icon with a `paths` entry for `shelving/ui/icon/UpIcon` in your `tsconfig.json`. See `README.md` in this folder.
