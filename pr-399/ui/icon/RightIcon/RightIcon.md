# RightIcon

- Kind: constant
- Import: `import { RightIcon } from "shelving/ui/icon/RightIcon";`

Chevron that points right, e.g. the separator in `<TreeBreadcrumbs>`.
- Default is the Heroicons `ChevronRightIcon`.
- Swap it for your own icon with a `paths` entry for `shelving/ui/icon/RightIcon` in your `tsconfig.json`. See `README.md` in this folder.
