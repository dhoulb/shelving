# ErrorIcon

- Kind: constant
- Import: `import { ErrorIcon } from "shelving/ui/icon/ErrorIcon";`

Icon for `status="error"` in `<Icon>`.
- Default is the Heroicons `XCircleIcon`.
- Swap it for your own icon with a `paths` entry for `shelving/ui/icon/ErrorIcon` in your `tsconfig.json`. See `README.md` in this folder.
