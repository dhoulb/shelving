# MenuIcon

- Kind: constant
- Import: `import { MenuIcon } from "shelving/ui/icon/MenuIcon";`

Icon to open a menu, e.g. the menu button on `<SidebarLayout>`.
- Default is the Heroicons `Bars3Icon`.
- Swap it for your own icon with a `paths` entry for `shelving/ui/icon/MenuIcon` in your `tsconfig.json`. See `README.md` in this folder.
