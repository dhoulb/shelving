# AddIcon

- Kind: constant
- Import: `import { AddIcon } from "shelving/ui/icon/AddIcon";`

Icon to add an item, e.g. the add button on `<ArrayInput>` and `<DictionaryInput>`.
- Default is the Heroicons `PlusIcon`.
- Swap it for your own icon with a `paths` entry for `shelving/ui/icon/AddIcon` in your `tsconfig.json`. See `README.md` in this folder.
