# RetryIcon

- Kind: constant
- Import: `import { RetryIcon } from "shelving/ui/icon/RetryIcon";`

Icon for `<RetryButton>`.
- Default is the Heroicons `ArrowPathIcon`.
- Swap it for your own icon with a `paths` entry for `shelving/ui/icon/RetryIcon` in your `tsconfig.json`. See `README.md` in this folder.
