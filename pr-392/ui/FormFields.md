# FormFields

- Kind: component
- Import: `import { FormFields } from "shelving/ui";`

Show a `<Field>` for every property in the current form's schema.

## Signatures

```ts
FormFields(): ReactElement
```

## Returns

| Type | Description |
| --- | --- |
| `ReactElement` | A fragment of `FormField` elements, one per schema property. |

## Examples

```ts
<FormFields />
```
