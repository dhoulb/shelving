# ColorVariants

- Kind: interface
- Import: `import { ColorVariants } from "shelving/ui";`

Variant props for colouring an element, e.g. `color="purple"`.

## Signatures

```ts
{
	color?: ColorVariant | undefined;
}
```

## Properties

| Property | Type | Description |
| --- | --- | --- |
| `color` | `ColorVariant \| undefined` | Colour of the element. Optional. |
