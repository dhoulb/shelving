# MetaAssets

- Kind: type
- Import: `import { MetaAssets } from "shelving/ui";`

Set of resolved linked assets in `(href)[]` format (hrefs already absolutified to `ImmutableURI`).

## Signatures

```ts
ImmutableArray<ImmutableURI>
```

## Types

- [ImmutableArray](../util/array/ImmutableArray.md): Immutable array: an array that cannot be changed.
- [ImmutableURI](../util/uri/ImmutableURI.md): Object that describes a valid URI, e.g. urn:isbn:0451450523 or http://example.com/path/to/resource
