# ShadowVariants

- Kind: interface
- Import: `import { ShadowVariants } from "shelving/ui";`

Variant props for the drop shadow of an element, e.g. `shadow="large"`.

## Signatures

```ts
{
	shadow?: ShadowVariant | undefined;
}
```

## Properties

| Property | Type | Description |
| --- | --- | --- |
| `shadow` | `ShadowVariant \| undefined` | Drop shadow of the element. Optional. |
