# PossibleMetaLinks

- Kind: type
- Import: `import { PossibleMetaLinks } from "shelving/ui";`

Set of input meta `<link />` tags in `{ rel: href }` format, before hrefs are resolved.

## Signatures

```ts
ImmutableDictionary<Nullish<PossibleLink>>
```

## Types

- [ImmutableDictionary](../util/dictionary/ImmutableDictionary.md): Readonly dictionary object.
- [Nullish](../util/null/Nullish.md): Nullish is the value or null or undefined.
- [PossibleLink](../util/link/PossibleLink.md): Anything that can be turned into an <a href>.
