# TintVariant

- Kind: type
- Import: `import { TintVariant } from "shelving/ui";`

Shades of the currently selected tint color, from `"00"` (black) through `"50"` (the hue itself) to `"100"` (white).

- `"contrast"` is black or white, whichever reads better on `"50"`.
