# SpaceVariants

- Kind: interface
- Import: `import { SpaceVariants } from "shelving/ui";`

Variants to control block spacing on components, e.g. `space="large"`.

## Signatures

```ts
{
	space?: SpaceValue | undefined;
}
```

## Properties

| Property | Type | Description |
| --- | --- | --- |
| `space` | `SpaceValue \| undefined` | Block spacing for this component. Optional. |
