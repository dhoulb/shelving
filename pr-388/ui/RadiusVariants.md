# RadiusVariants

- Kind: interface
- Import: `import { RadiusVariants } from "shelving/ui";`

Variant props for the corner radius of an element, e.g. `radius="large"`.

## Signatures

```ts
{
	radius?: RadiusVariant | undefined;
}
```

## Properties

| Property | Type | Description |
| --- | --- | --- |
| `radius` | `RadiusVariant \| undefined` | Corner radius of the element. Optional. |
