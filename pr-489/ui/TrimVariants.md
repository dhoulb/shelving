# TrimVariants

- Kind: interface
- Import: `import { TrimVariants } from "shelving/ui";`

Variant props to trim the outer margins of a component's first and last children, e.g. `trim`.

## Signatures

```ts
{
	trim?: boolean | undefined;
}
```

## Properties

| Property | Type | Description |
| --- | --- | --- |
| `trim` | `boolean \| undefined` | Trim the start margin of the first child and the end margin of the last child. Optional. |
