    Imagecomponent

    Image({ src, alt, className, ...props }: ImageProps): ReactElement
    ParamType
    propsImageProps
    Props for Image — an src, optional alt text, plus space and width variants. required
        .srcstring
    required
        .altstring
    Return
    ReactElement

    Image block — renders an <img> with space and width variants applied.

    • It loads lazy, and fades in once when it loads. An image that is already loaded when it mounts shows at once.
    • It never holds a transition (such as a page change): React waits only for an eager <img> with no onLoad.
    • The load state is the data-loaded attribute (none, fade, then done), set on the element directly, so a load never re-renders.

    An image block. Renders an <img> with square corners and a block margin. Use it for artwork such as a logo, an icon or a transparent PNG. For a photo, use <Photo>.

    Things to know:

    • Always set alt to describe the image for screen readers. Set alt="" for an image that is only decoration.
    • It loads lazily, and fades in once when it loads. An image that is already loaded when it mounts (for example, from the cache) shows at once with no fade.
    • It never holds a page transition. React waits only for an eager <img> with no onLoad.
    • The load state is on the data-loaded attribute: none, then fade, then done. It is set on the element directly, so a load never renders the component again.
    • With scripts off, the image shows at once.
    • With reduced motion, the image shows with no fade.
    • object-fit: cover keeps the image in proportion when you give it a fixed size.
    • Composes the space and width variants.
    • Inside <Prose> a raw <img> gets the same box styles.
